# AI YALY Telegram Bot

Telegram-бот на Python для экспериментов с текстовыми и мультимодальными ИИ-функциями.

## Возможности
- Диалог с ИИ
- Работа с изображениями и их распознавание
- Эксперименты с генерацией изображений и речи
- Хранение истории в SQLite

## Запуск
Установите зависимости из requirements.txt. Перед запуском задайте Telegram- и API-ключи через переменные окружения или локальный файл конфигурации, исключённый из Git. Точка входа находится в каталоге app/.

## Безопасность
Не публикуйте токены, персональные данные и базы истории. Для развёртывания ограничьте доступ к логам и данным.

## Статус
Учебный прототип; функции зависят от конфигурации API.
